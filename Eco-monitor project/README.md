# О проекте
1. ## Цель проекта
«Разработать прототип системы “Эко‑Монитор” для автоматического мониторинга биоразнообразия по аудио‑записям голосов птиц. Система должна выявлять видовой состав, оценивать активность видов и сигнализировать о потенциальных аномалиях в экосистеме.»

2. ## Архитектура решения
*Датасет*/*: локальный слепок аудиодатасета с голосами птиц (16 941 запись) с разметкой по видам.

*Предобученная модель YAMNet*: модель Google для классификации звуков окружающей среды, используемая как экстрактор высокоуровневых аудио‑признаков (эмбеддингов).

*Дообученный классификатор*:
- поверх эмбеддингов YAMNet обучен собственный классификатор для 17 видов птиц (transfer learning);
- модель специализируется именно на птичьих вокализациях выбранного набора видов.

*Эмбеддинги*: компактное представление аудио‑окна, на котором работает классификатор; именно они позволяют обрабатывать большие объёмы данных эффективно.

*Вывод* основных входных параметров и результатов обработки данных с построением гистограммы.

3. ## Используемые данные и модели

Аудиоданные (слепок сохранён локально в каталоге birds_saved_full, содержит ~16 941 запись голосов 17 видов птиц) https://huggingface.co/datasets/Saads/birdsounds - загружены первые ~5GB;

[YAMNet](https://www.kaggle.com/models/google/yamnet/tensorFlow2/yamnet/1?tfhub-redirect=true)
YAMNet используется только как предобученный экстрактор эмбеддингов, его веса не изменяются. Дообучение проводится только для верхнего классификатора видов птиц на эмбеддингах, извлечённых YAMNet;

Дообученный классификатор адаптирет систему к конкретному датасету birdsounds (17 видов) и в результате получаем модель для мониторинга биоразнообразия, не обучая огромную нейросеть с нуля.

4. ## Алгоритм работы
*Загрузка и подготовка данных*
Аудиозаписи читаются из слепка датасета.
Каждая запись декодируется из двоичного формата, приводится к единой частоте дискретизации (16 кГц) и нормализуется по уровню сигнала.

*Разбиение на временные окна*
Запись делится на перекрывающиеся окна (например, 5 секунд с шагом 2.5 секунды).
Такое скользящее окно позволяет «просмотреть» звуковую среду во времени и не пропускать короткие вокализации.

*Извлечение признаков и классификация*
Для каждого окна считаются эмбеддинги с помощью предобученной YAMNet.
Эмбеддинги подаются в дообученный классификатор птиц, который выдаёт наиболее вероятный вид для данного окна.

*Агрегация по видам и оценка состояния*
Считается, сколько окон было отнесено к каждому виду (частота детекций).
Определяется количество «активных видов» — сколько разных видов вообще зафиксировано в выбранной выборке.

На основе этих данных система вычисляет простый индикатор аномалии (например, если активных видов заметно меньше заданного порога или ключевые виды отсутствуют).

*Вывод результатов*
Строится гистограмма (бар‑чарт) активности видов: по оси X — виды, по оси Y — количество детекций.
В текстовом виде выводится:
- число активных видов;
- общее количество проанализированных окон;
- флаг «аномалия / нет аномалии».

5. ## Интерпретация результатов
Гистограмма активности видов показывает, какие виды доминируют в звуковой среде. Равномерное распределение с большим количеством видов соответствует более богатой и «здоровой» экосистеме; сильное доминирование 1–2 видов или резкое уменьшение числа активных видов может быть признаком деградации местообитаний, шума, антропогенного воздействия.

*Число активных видов*
Это простая оценка видового богатства (richness) по аудиоданным. При регулярном мониторинге снижение этого показателя по времени или по участкам может подсказать, где происходят негативные изменения.

*Аномалия*
В простейшей конфигурации аномалией считается ситуация, когда число активных видов падает ниже заданного порога. В дальнейшем правило может быть расширено (учёт ключевых/редких видов, пороги по индексу разнообразия и др.), что делает систему пригодной для раннего обнаружения деградации местообитаний.

*Выявление трендов и аномалий*
При запуске на большем количестве записей (или в разные моменты времени) можно сравнивать показатели: число видов, форму распределения по видам, индексы разнообразия.

Это позволяет отслеживать динамику и автоматически подсвечивать зоны потенциального ухудшения состояния экосистемы.

*Визуализация и поддержка принятия решений*
Гистограмма активности видов — основной визуальный элемент, который понятен специалисту: сразу видно, какие виды присутствуют и насколько активно.

*Числовые метрики* (количество видов, окон, флаг аномалии) можно использовать в отчетах и дашбордах для управления охранными мероприятиями.

6. ## Описание и развитие проекта
Проект «Эко‑Монитор» — это прототип системы для мониторинга состояния экосистемы по биоакустическим данным. В качестве источника информации используются записи голосов птиц, которые отражают структуру и активность сообществ на исследуемой территории. Система автоматически обрабатывает большие массивы аудио, выделяет виды птиц, оценивает их активность и выявляет возможные аномалии (снижение разнообразия, доминирование отдельных видов, отсутствие активности в предполагаемо «живом» участке) и может быть расширена на анализ спутниковых снимков / камер‑ловушек с анализом графических данных. В качестве результата может быть реализовано уведомление любым из существующих видов e-mail, мессенджер, дашборд или любая контрольная панель.

2. *Подготовка данных*
По умолчанию проект ожидает следующую структуру каталогов на Google Drive:

BASE_DIR      = "/content/drive/MyDrive"
DATASET_DIR   = os.path.join(BASE_DIR, "birds_saved_full")

*Необходимо*:
Скачать и скопировать на свой Google Drive папки:

https://drive.google.com/drive/folders/1C4Rm_ZdFKOUv-apyPxAzLAL7YNI9re-G?usp=sharing

Открыть ноутбук Eco_monitor.ipynb в Google Colab.

В первой ячейке будет выполнено подключение Google Drive:

После успешного монтирования запустить все ячейки (Runtime → Run all / «Среда выполнения → Выполнить всё»).

4. Результат работы

- количество активных видов;

- гистограмму активности видов (bar‑chart с видами по оси X и числом детекций по оси Y).


## Расчет точности модели
В конце проекта располагаются ячейки с кодом для расчета точности получившейся модели.
Точность дообученного классификатора, оцененная на первых 1000 записях датасета birdsounds (после исключения записей с меткой, отсутствующей в encoder), составляет около 80% (accuracy = 0.799). F1‑мера по большинству видов находится в диапазоне 0.7–0.9, что подтверждает корректность работы прототипа для задач мониторинга.
