# Курсовая работа: Классическое машинное обучение в хемоинформатике
> Прогнозирование эффективности и токсичности лекарственных соединений на основе молекулярных дескрипторов (задачи регрессии и бинарной классификации)

**Студент:** Лучин Илья Игоревич  
**ВУЗ:** НИЯУ МИФИ | 1 курс, 2 семестр  
**Дисциплина:** Классическое машинное обучение

## Структура проекта
| Файл | Описание |
|------|----------|
| `1. Загрузка и анализ данных (EDA).ipynb` | Предобработка, анализ распределений, выбросов (IQR), корреляций, PCA, сохранение чистых данных |
| `2. Регрессия для IC50.ipynb` | Прогнозирование концентрации ингибирования вируса. Сравнение 5 моделей, GridSearchCV, анализ остатков |
| `3. Регрессия для CC50.ipynb` | Прогнозирование цитотоксичности. Диагностика переобучения, калибровка, сравнение с задачей IC50 |
| `4. Регрессия для SI.ipynb` | Прогнозирование индекса селективности. Работа с производной переменной, оценка накопления ошибок |
| `5. Классификация. Предсказание IC50 больше медианы.ipynb` | Бинарная классификация эффективности. Стратифицированное разбиение, ROC-AUC, F1 |
| `6. Классификация. Предсказание CC50 больше медианы.ipynb` | Бинарная классификация токсичности. Лучший результат проекта (AUC=0.859) |
| `7. Классификация. Предсказание SI больше медианы.ipynb` | Относительная селективность. Анализ переобучения, пороговая настройка |
| `8. Классификация. Предсказание SI больше 8.ipynb` | Классификация по фарм. стандарту. Работа с несбалансированными классами, анализ Precision/Recall |
| `Отчет.pdf` | Аналитический отчёт: сводные таблицы, сравнение моделей, выводы и рекомендации |


## Технологический стек
- **Язык:** Python 3.10+
- **Data & ML:** `pandas`, `numpy`, `scikit-learn`, `xgboost`, `lightgbm`, `scipy`
- **Визуализация:** `matplotlib`, `seaborn`
- **Методы:** 5-Fold CV, `GridSearchCV`, `RobustScaler`, `log1p`-преобразование, анализ остатков, Confusion Matrix, ROC/PR-кривые
- **Метрики:** `R²`, `RMSE`, `MAE`, `ROC-AUC`, `F1-score`, `Precision`, `Recall`
